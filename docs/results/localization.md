# Localization: Grad-CAM / forgery-mask agreement

**G8 is measured, not downgraded.** CASIA 2.0 ships pixel masks — one `*_gt.png` per
tampered image (`CASIA 2 Groundtruth`, 5,123 files) — in the same Kaggle dataset as the
images. The S0 readiness gate reported `mask_available: false`; the masks are nevertheless
there and usable, so this goal reports IoU/Dice rather than an unavailable-feature note.

Generated by `python -m analysis.localization`.

Checkpoint: `efficientnet_b0_ela_s3_best.pth` — the best validation run of the 224 px ELA
grid, i.e. the strongest single stream trained in the sweep.
Masks: the Kaggle dataset's `CASIA 2 Groundtruth` folder, staged locally as symlinks with the
`_gt` suffix stripped so the stems match the images. Matched to tampered images by exact,
case-insensitive filename stem only; no fuzzy or suffix matching is used.
Model: efficientnet_b0 / ela.

Threshold on the Grad-CAM value in [0, 1]: 0.40, chosen on the val split's masks only (mean IoU 0.1249).

## What the numbers mean

The classifier is not segmenting forgeries. Mean IoU 0.114 is only 1.45× the 0.079 an
all-forged constant mask scores against these same masks, and about 1.9× a random mask with
the same 21.4% coverage (independence approximation, ≈0.06). Grad-CAM therefore carries real
but weak spatial signal for this model; it is not usable as a localization output.

Two known causes, both by construction:

- **CAM resolution.** EfficientNet-B0 at 224 px yields a 7×7 CAM, so one CAM cell spans
  32×32 input pixels while the masks are full resolution. The 320 px retry, if it is
  reported, gives a 10×10 CAM and a correspondingly finer grid.
- **Where the stream looks.** This checkpoint reads ELA, whose signal is diffuse
  (recompression mismatch across the whole image), not a compact tampered patch. The RGB
  stream is the better candidate for localization and was not measured here.

Reported descriptively, as the design specifies: no claim of localization quality enters
the headline metrics.

## Reproduce

CPU only, about one minute for the 295 scored images plus the val calibration pass.

```bash
# 1. split CSVs whose image paths point at the local CASIA copy:
#    /kaggle/working/casia_link/CASIA2.0_revised/  ->  <casia>/CASIA2/
# 2. masks/*.png symlinks to "<casia>/CASIA2/CASIA 2 Groundtruth/*_gt.png"
#    with the _gt suffix stripped from the stem
python -m analysis.localization \
  --ckpt models/efficientnet_b0_ela_s3_best.pth \
  --data-dir <staged>/data --masks-dir <staged>/masks \
  --split test --out docs/results/localization.md
```

Masks exist for 5,123 of the 5,125 tampered images; the 8 test images without a mask are
excluded from scoring, never scored as zero.
