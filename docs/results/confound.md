# JPEG-quality confound analysis

Generated by `python -m analysis.confound`.
Each run is scored at the threshold stored in its own prediction artefact (the one it reported), not a shared 0.5. Per-bin macro-F1 is scored only where both classes have at least 20 images; other bins are reported as insufficient and contribute nothing to the average.
Quality factors are read from the JPEG quantization tables. Images without one (BMP/TIFF) and images that could not be opened are excluded from both tests, never coerced to 0, and counted separately below.
Macro-F1 restricted to JPEG images is reported too: when one class is mostly JPEG and the other mostly TIFF/BMP, the full-split score can reward file format rather than forgery evidence.
